# Chinhoyi Solar Streetlight Dashboard

An interactive GIS spatial analysis dashboard for monitoring, mapping, and optimizing solar streetlight networks in Chinhoyi.

🌐 **Live Demo:** [chinhoyi-solarstreetlight-dashboard-3.onrender.com](https://chinhoyi-solarstreetlight-dashboard-3.onrender.com)

---

## 📌 Features
* **Interactive Mapping:** Spatial visualization of streetlight points and coverage buffers using Folium.
* **Network Analysis:** Multi-criteria decision analysis to identify optimal solar lighting placements.
* **Containerized Deployment:** Fully Dockerized application ready for production deployment on Render.

---

## 🛠️ Tech Stack
* **Language:** Python
* **GIS & Mapping:** Streamlit, Folium, GeoPandas
* **Containerization:** Docker
* **Hosting:** Render
